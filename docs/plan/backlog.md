# CodeMap backlog


## Commit diff view (added 2026-10-03)
Pick a git commit (or a range) and see its changes on the map in detail: highlight the blocks and connections that were added, changed or removed, show line counts per block, and let you click a changed block to see its full side-by-side diff. Useful for reviewing a PR or understanding what a commit really touched.

## Code inspector (added 2026-10-03)
Click a block on the map to open its source in a read-only Monaco editor panel inside the app: syntax highlighting, go-to-definition within the project, search, and jumping between the block's files. Read only, with no editing; an "Open in editor" button hands off to your real editor. Pairs with the commit diff view, using Monaco's diff mode.

## Branding idea (added 2026-10-03)
Tagline: "Turning the lights on in the Dark Factory." Pick a light-related product name to match (candidates under discussion: Floodlight, Lantern, Lumen, Klieg, Beacon). Check name and domain availability before choosing.

## Website art direction (added 2026-10-03)
Atmospheric dark factory: a near-black, moody industrial space with soft volumetric light shafts cutting through haze and lighting up the machinery, in the spirit of Playdead's Inside (muted palette, silhouettes, side-on depth, fog). As you scroll, more light shafts open and reveal the map. Pairs with the tagline "Turning the lights on in the Dark Factory" and a light-related name (Lightwell is a top contender). Use original art only, never game assets.
