# Security

If you believe you have found a security vulnerability in Lightwell or related Moonbase 2090 software, please email **security@moonbase2090.com**.

Include:

- What you found and which component is affected (desktop app, CLI, website, etc.)
- Steps to reproduce
- Impact if you know it

Please do not open a public GitHub issue for security-sensitive reports. We will acknowledge your message and work on a fix.
